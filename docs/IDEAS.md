# Ideas

One line each. An idea earns a pitch only when a gate or a measurement asks for it.

- **Hours watched, estimated.** Takeout has no durations. Honest only with an explicit assumption
  (e.g. a per-video average the user sets) and the range it implies. Related searches ask for it:
  "how much time have i spent on youtube calculator". (organic-traffic, 2026-11-15)
- **Search history.** `search-history.json` sits next to the watch history in the same Takeout.
  Unmeasured demand. (organic-traffic, 2026-11-15)
- **YouTube Music recap.** The export mixes YouTube Music views in. A separate view is cheap once the
  year recap exists. (organic-traffic, 2026-11-15)
- **Shareable recap image.** Recap cards are what people share in December. Rendered in the tab, no
  upload. (organic-traffic, 2026-11-15)
- **Read the PDF/image/OCR result pages** that Google's block stopped on 2026-11-15, before anyone
  proposes work on a kept OCR or EXIF tool. (organic-traffic, 2026-11-15)
- **Inbound links to TubeTrace before 2026-10-18.** Build `8f6b5d9` and run the link graph to see
  whether PR #18 cut links to the page the week its impressions fell. (organic-traffic, 2026-11-15)
